# GSoC 2026 — CERN-HSF / ATLAS TileCal -- Initial 

**Applicant:** Priyabrata

This repository contains reproductions of two ATLAS TileCal papers as part of the GSoC 2026 inital task for understanding the problem statement for CERN-HSF. All implementations are from scratch using publicly available algorithms; no real ATLAS detector data is used (see [Notes on Data](#notes-on-data)).

---

## Overview

| # | Paper | Topic | Directory |

## Key Results

### Paper 1 — Optimal Filtering

| Result | Reproduced |
|--------|-----------|
| OF2 weights computed via autocorrelation matrix | Yes |
| Energy resolution ~1% for high-amplitude signals | Yes |
| Timing resolution degrades at low amplitude (noise-dominated) | Yes |
| Quality factor χ² distribution | Yes |
| CIS calibration curve (linear ADC response) | Yes |

### Paper 2 — ML Reconstruction

| Model | Parameters | Loss (hybrid) |
|-------|-----------|---------------|
| MLP | 148 | 0.5·MAE + 0.5·RMSE |
| CNN | 147 | 0.5·MAE + 0.5·RMSE |

Both models match the parameter counts in the paper and are designed to fit within FPGA resource constraints.

## How to Run

### Prerequisites

```bash
pip install -r requirements.txt
```

### Paper 1 — Optimal Filtering

```bash
cd optimal_filtering/
jupyter notebook tilecal_optimal_filtering_2005.ipynb
```

Run all cells in order. The notebook is self-contained and generates all figures in `figures/`.

### Paper 2 — ML Reconstruction

```bash
cd ml_reconstruction/
jupyter notebook tilecal_ml_reconstruction.ipynb
```

> **Memory note:** The default `n_bunch_crossings` can be reduced if memory is limited. The notebook documents this parameter at the top of the data-generation cell.

## Notes on Data

No real ATLAS detector data is publicly available for TileCal pulse reconstruction. Both reproductions use **synthetic data** generated from the known pulse shapes and noise models described in the respective papers:

- **Paper 1:** Pulse shape `h(t)` is the standard TileCal reference shape; noise is modeled as Gaussian with the autocorrelation matrix from the paper.
- **Paper 2:** Synthetic pile-up samples are generated by superimposing scaled pulse shapes across multiple bunch crossings, matching the HL-LHC conditions described in the paper.
